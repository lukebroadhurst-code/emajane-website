# EMAJANE website

Static homepage for EMAJANE (Emma Jane Charnley). Plain HTML, CSS and one small script. No build step.

- `index.html` is the page. `brand.css` holds the design tokens. `shared.js` draws the smoke.
- Fonts are embedded in `assets/fonts.css` (Cormorant Garamond, Marcellus, Inter Tight; all SIL Open Font Licence).
- The page is marked `noindex` while it still contains placeholder content: gig dates and venues, prices, the tee, and links set to `#`.
- Source of truth for the design is the brand project (`emajane-brand/source/`). Change things there, then copy `home.html`, `brand.css`, `shared.js` and the assets across.
